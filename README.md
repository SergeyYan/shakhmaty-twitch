# Шахматы твич

**[Скачать готовую игру ZIP](https://github.com/SergeyYan/shakhmaty-twitch/releases/latest/download/chess-twitch.zip)** · [Релизы](https://github.com/SergeyYan/shakhmaty-twitch/releases)

Распакуйте весь ZIP в одну папку и откройте `index.html`.

Локальная HTML-игра: стример против Twitch-чата. Откройте **index.html** двойным щелчком. Все необходимые скрипты, включая chess.js 1.4.0, находятся в папке проекта. Интернет нужен для Twitch; шрифт имеет системную замену.

Альтернативный запуск: `npm start`, затем http://127.0.0.1:4173. Установка npm-пакетов не нужна. `npm test` — проверки, `npm run build` — готовая папка `dist`.

## Начало партии

1. Введите логин Twitch-канала без ссылки и нажмите «Подключить».
2. Дождитесь подтверждения подключения, выберите цвет стримера, нажмите «Начать партию».
3. Стример ходит щелчками: фигура, затем клетка назначения. Допустимые ходы подсвечены.
4. Зрители голосуют сообщениями `!E7E5`. Регистр не важен. Поддержан и формат `e7e5`.

Один зритель — один текущий голос. Новая допустимая команда заменяет предыдущую; недопустимая не удаляет голос. На ходу чата через 60 секунд выполняется самый популярный допустимый ход; при равенстве — первым получивший текущий голос. Голоса очищаются после хода. Голоса на ходу стримера не сохраняются.

На каждый ход даётся новая минута. Если стример не успел или чат не дал ни одного допустимого голоса, сторона проигрывает по времени. Таймер считается по абсолютному дедлайну, а не количеству срабатываний интервала. Держите страницу открытой и компьютер активным: спящий компьютер не сможет вовремя исполнить ход.

## Реплики фигур

Каждое сообщение из чата повторяет случайная фигура команды чата. `@e7 Вперёд!` адресует реплику своей фигуре на e7. Команду хода повторяет исходная фигура. Видно до трёх реплик одновременно; они исчезают через 5,5 секунды. Текст выводится безопасно через textContent, HTML не исполняется. Переключатель отключает реплики.

## Правила

Проверка ходов — chess.js 1.4.0 (BSD-2-Clause, лицензия в vendor/chess.LICENSE). Поддерживаются шах, мат, пат, рокировка, взятие на проходе, четыре варианта превращения, недостаток материала, повторение позиции и правило 50 ходов. Ничья при троекратном повторении и 50 ходах фиксируется автоматически. Ход пешки на две клетки разрешён только с начального ряда. При превращении чат указывает Q/R/B/N: `!E2E1N`; без буквы — ферзь. Стример выбирает фигуру в окне. История экспортируется в PGN.

## Twitch и пробный режим

Чтение чата использует защищённый WebSocket IRC Twitch и анонимное read-only подключение justinfan. Пароль, OAuth и отправка сообщений в Twitch не нужны. Подключение подтверждается ответом сервера для указанного канала. Это не проверка существования или статуса трансляции канала: Twitch может позволять вход в пустые комнаты. При ошибке или разрыве виден статус; переподключение выполняется кнопкой. Во время разрыва таймер продолжает идти, уже принятые голоса сохраняются. Изменение имени канала действует только после нажатия «Переподключить».

Анонимный IRC не является гарантированным публичным контрактом Twitch и может перестать работать. Для промышленной интеграции Twitch рекомендует EventSub с авторизацией: https://dev.twitch.tv/docs/chat/ .

«Попробовать без Twitch» позволяет начать партию и вводить тестовые сообщения внизу чата. Меняйте имя зрителя для независимых голосов. Это отдельный режим, сообщения не отправляются в Twitch. При подключении настоящего канала тестовый ввод скрывается. Для OBS используйте захват окна браузера; не публикуйте управление стримера как общедоступную страницу.

## Файлы

- index.html / style.css — интерфейс.
- game-session.js — состояние партии, дедлайны, голоса.
- twitch-chat.js — подключение и разбор IRC.
- app.js — взаимодействие доски и интерфейса.
- piece-art.js — собственные SVG-силуэты фигур с явными цветами.
- vendor/chess.js — локальная библиотека правил с browser-обёрткой.
- server.cjs / build.cjs — необязательный предпросмотр и копирование сборки.
- tests/game.test.cjs — регрессионные проверки правил, таймера, голосов и IRC.
- tests/fast-games.test.cjs — ускоренные партии и специальные шахматные позиции; виртуальное время без изменения игрового лимита.

Название игры — «Шахматы твич», надпись в интерфейсе — «Чат делает ход». Проверки перед выпуском описаны в TEST_REPORT.md в репозитории.
